WEBSITE HAS 3 UNITS:
~ client (the user that uses browser to connect with server)
~ server (the place where clients interact with websites)
~ browser (the engine that brings websites to clients from server)
CLIENT --> BROWSER --> SERVER --> BROWSER --> CLIENT

FRONTEND MADE THROUGH html, css, javascript
HTML --> the skeleton of websites
CSS --> the appearance of websites
JAVASCRIPT --> to add interaction with websites (client side scripting)
hence, css adds beauty and javascript adds brain

to start the html coding, type '!' and hit enter.
the basic format appears forehand. to link the css page, type 'link' and press css option, then edit the css filename. it comes in head tag.
to connect javascript file, type 'script' and select src option. edit name of js file. it comes in body tag.
