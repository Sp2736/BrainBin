Engineering Mathematics - 2 This subject provides essential mathematical techniques for engineering applications. It covers differential equations, matrix algebra, multiple integrals, and probability concepts. Students learn to model and solve real-world problems using analytical methods and statistical tools. Programming With C++ This subject introduces students to advanced programming using the C++ language, building on prior knowledge from foundational computing courses. It covers core topics such as object-oriented programming, memory management, file handling, templates, and the use of the Standard Template Library (STL). Through theory and practical sessions, students learn to design modular, efficient, and maintainable C++ programs for real-world applications. Reading Notes Practical Codes Practice Assignments CodeWithHarry Cheatsheet
Digital Electronics This subject introduces the fundamentals of digital electronics, focusing on number systems, Boolean algebra, and digital logic circuits. Students learn to design and analyze combinational and sequential circuits such as adders, multiplexers, flip-flops, and counters. The course also covers processor logic design including memory units and processor organization. It builds a strong foundation for understanding digital systems used in computing and embedded applications. Reading Notes Practical Questions Practice Assignments
