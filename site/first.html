First Semester Subjects

Subject & Syllabus Description Study Material
Engineering Mathematics - 1 This course develops foundational skills in differential calculus, series analysis, matrix algebra, and multivariable calculus, essential for engineering applications. It begins with higher-order derivatives and progresses through complex numbers, matrix operations, and partial differentiation. Students will apply these tools to solve real-world problems involving optimization, approximation, and systems of equations. Reading Notes Class Work Examples Practice Examples Practice Assignments
Computer Concepts and Programming This course introduces foundational computer and programming concepts using C, covering data types, control structures, arrays, and strings. It progresses into user-defined functions, structures, pointers, dynamic memory allocation, and file handling. Through theory and hands-on practice, students build problem-solving skills and develop complete C programs for varied applications. Reading Notes Practical Codes Practice Assignments CodeWithHarry Material
Basics of Electronics and Electrical Engineering This course provides a comprehensive introduction to fundamental electrical and electronics principles, starting from basic components and circuit laws to AC/DC systems. It covers electrostatics, electromagnetism, single and polyphase circuits, and key electronic devices like diodes and transistors. Through theoretical concepts and practical sessions, students gain hands-on skills for analyzing and designing basic electrical-electronic systems. Reading Notes Practice Questions Practice Assignments
ICT Workshop This hands-on course introduces students to core ICT skills including computer hardware, OS installation, Linux commands, and networking basics. It emphasizes real-world applications through GitHub collaboration, Google Workspace tools, and IoT projects using Arduino, ESP32, and Raspberry Pi. By the end, students gain practical experience in system setup, sensor interfacing, and basic automation. Reading Notes Practical Files
Communication English This course builds essential communication skills in English through practical listening, speaking, reading, and writing activities. It focuses on real-life language functions, grammar usage, and vocabulary development for academic and professional contexts. Students gain confidence to interact fluently and effectively using English in diverse situations. Reading Materials
